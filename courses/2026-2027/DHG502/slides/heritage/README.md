# Digital Heritage · DHG 502 Week 8

Open `index.html` in a browser. To play the YouTube videos inside the slides, serve the folder instead of opening the file directly:

    cd courses/2026-2027/DHG502/slides/heritage
    python3 -m http.server 8000

then open http://localhost:8000. (YouTube blocks embeds on pages opened as `file://`; there each video slide shows a thumbnail that opens the video on YouTube. A link is also printed under every video.)
