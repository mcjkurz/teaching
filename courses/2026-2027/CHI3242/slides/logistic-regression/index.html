TF-IDF：哪些詞真正重要？TF-IDF: which words really matter?

tf（詞頻）：這個詞在這篇出現幾次term frequency: how often the word occurs in this document
df（文件頻率）：多少篇有這個詞；越少見，idf 越大document frequency: how many documents contain it; rarer words get a larger idf
\(\text{tfidf}(w) = \text{tf}(w) \times \log\dfrac{N}{\text{df}(w)}\)
詞 wordtfdfidf = log(N / df)TF-IDF

算一次預測One prediction: features in, a probability out

邏輯迴歸：輸入一篇評論，輸出「正面」的機率logistic regression takes a review and outputs the probability that it is positive
① 輸入：每個詞的 TF-IDF 值 x；沒出現的詞 x = 0input: the TF-IDF value of each word; absent words are 0
② 每條線一個權重 w：綠 ＝ 拉向正面，紅 ＝ 拉向負面，越粗越重要every wire has a weight; green pulls towards positive, red towards negative
③ 加權總分：\(z = 0.88 + 0.01 + 0.10 = 0.99\)multiply, add up, add the bias b: the same weighted sum as the SVM in stylometry
④ 新的一步：\(p = \sigma(0.99) \approx 0.73 \ge 0.5\) → 正面new: the sigmoid turns the score into a probability
「電影」到處都出現 → 權重 ≈ 0a ubiquitous word like 電影 learns a weight near zero

怎麼學出 w 和 b？How are the weights learned?

找一組 w、b，讓模型在已標註的資料上「錯得最少」find the w and b that are least wrong on the labelled data
交叉熵損失（y 是真實標籤）the cross-entropy loss (y is the true label)
\(L = -[\,y\log p + (1-y)\log(1-p)\,]\)
梯度下降：往損失變小的方向走一小步；η ＝ 步子大小gradient descent: step downhill; η is the learning rate
\(w \leftarrow w - \eta \dfrac{\partial L}{\partial w}\)
預測得越錯，損失越大 → 模型就是這樣「知道自己錯了」the wronger the prediction, the bigger the loss: this is how the model registers its mistakes

三個類別？SoftmaxMore than two classes: softmax

每個類別一個分數 \(z_k\)；全部變成正數，再歸一化one score per class; exponentiate, then normalize
\(p_k = \dfrac{e^{z_k}}{\sum_j e^{z_j}}\)
選機率最大的類別：正面（72%）pick the class with the highest probability
類別 class分數 \(z_k\)\(e^{z_k}\)機率 \(p_k\)

機率總和 ＝ 1；只有兩類時，softmax 就等於 sigmoidprobabilities sum to 1; with two classes, softmax reduces to the sigmoid

訓練集與測試集Train / test split: never grade the model on its own homework

500 篇已標註的評論，先隨機打亂，再切成兩份shuffle 500 labelled reviews, then split them in two
訓練集 training set400 篇 · 80%
測試集 test set100 篇 · 20%
① 只用訓練集學出 w、blearn the weights on the training set only
② 用模型沒看過的測試集評估evaluate on reviews the model has never seen
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
