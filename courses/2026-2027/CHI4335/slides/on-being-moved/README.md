# 被感動 · CHI 4335 第 8 週

Open `index.html` in a browser. To play the YouTube video inside the slide, serve the folder instead of opening the file directly:

    cd courses/2026-2027/CHI4335/slides/on-being-moved
    python3 -m http.server 8000

then open http://localhost:8000. (YouTube blocks embeds on pages opened as `file://`; there the slide shows a thumbnail that opens the video on YouTube.)

Gwangju photographs go in `img/gj/02.jpg` … `09.jpg`; empty slots show the expected file name.
