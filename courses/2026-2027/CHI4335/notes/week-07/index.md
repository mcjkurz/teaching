<h1>第7週　創傷與社會</h1>

<h2>陶東風：〈走向建構主義的文化創傷理論〉</h2>
<p>上週我們把創傷理解為個人經驗：一個無法與其他時刻相連的「現在」，一再回返（奧布萊恩）。本週的問題是：一個<strong>群體</strong>的創傷是怎麼形成的？陶東風此文介紹以傑弗里·亞歷山大（Jeffrey C. Alexander）為代表的<strong>文化創傷（cultural trauma）</strong>理論，其核心主張是：</p>
<p><strong>創傷不是生而為創傷的，而是變成創傷的。</strong>（套用波伏娃的名言；頁36）</p>
<p>創傷並非自然存在，而是符號／表徵的建構。文化創傷理論要揭示的，正是這個建構的過程和機制。</p>

<h3>一、從個體創傷到文化創傷</h3>
<p>「創傷」原是精神分析的範疇，研究對象是個人。社會學家凱·埃里克森（Kai Erikson）最早區分了兩種創傷（頁39）：</p>
<ul>
<li><strong>個人創傷：</strong>「對於心理的猛烈一擊」，突然、暴烈地穿透了個人的防衛。</li>
<li><strong>集體創傷：</strong>「對於社會生活基本紋理的猛烈一擊」，它「摧毀了將人群聯繫在一起的紐結，破壞了共同體感受」，往往緩慢地、不知不覺地滲入意識。</li>
</ul>
<p>文化創傷可以被個人經驗到，但<strong>必須觸及集體層次</strong>：它動搖的是集體身份認同，即「我們是誰，我們來自何處，我們要往哪裡去」（頁40）。</p>
<p>這套理論誕生於1999–2000年斯坦福大學行為科學高等研究中心的一個學術年，成果是亞歷山大等人主編的《文化創傷與集體身份》（2004）。成員之間也有分歧：吉森認為戰後被逐出波蘭的德國難民也受了創傷，什托姆普卡堅決反對。可見<strong>「誰的苦難算創傷」從來不是自明的</strong>。</p>

<h3>二、批判「自然主義」</h3>
<p>亞歷山大反對他所謂的<strong>「常民創傷理論」（lay trauma theory）</strong>：誰遭遇了可怕的事，誰就受了創傷（頁36）。它有兩個版本：</p>
<ul>
<li><strong>啟蒙版：</strong>創傷取決於事件本身，震驚與悲慟是理性人的自然反應（如尼爾〔Arthur Neal〕）。</li>
<li><strong>精神分析版：</strong>事件被壓抑到無意識，以夢魘、反常行為不斷回歸（如上週的卡魯斯〔Cathy Caruth〕）。</li>
</ul>
<p>兩者都犯了<strong>「自然主義謬誤」</strong>：把創傷當作不依賴符號建構的客觀事實。亞歷山大的反命題是：「事件並非本然具有創傷性質。創傷是受到社會調節／中介的屬性。」（頁37）換言之：</p>
<ul>
<li>常民理論：事件 → 創傷</li>
<li>建構主義：事件 → 承載群體的聲稱與表徵 → 文化創傷</li>
</ul>
<p>同一事件在某個社會、某個時期是創傷，在另一處可能就不是。用亞歷山大的話說：<strong>「社會危機必須成為文化危機。事件是一回事，對事件的再現又是另一回事。」</strong>（頁37）</p>

<h3>三、「想像的事件」與陶東風的立場</h3>
<p>亞歷山大甚至說：「有時候引發深刻創傷的事件，並沒有真地發生」，想像的事件同樣能造成創傷（頁37）。他的例子是納粹宣稱「國際猶太陰謀」導致德國一戰戰敗。他不判斷聲稱的真假，只問聲稱如何被提出、結果如何。</p>
<p>陶東風對此有保留：照這種激進建構主義，傷害是否真實發生並不重要，創傷感可以無中生有地被召喚出來。他自己傾向<strong>「以客觀事件為基礎的建構論」</strong>（頁38）：</p>
<ul>
<li><strong>艾爾曼的「創傷潛力」：</strong>震撼性事件是創傷的必要條件，但不是充分條件，還需要符號表徵的操作。</li>
<li><strong>什托姆普卡的「創傷的土壤」：</strong>劇烈的社會變遷只是土壤，不是創傷本身。反過來，極具創傷潛力的事件也可能因為<strong>「被解釋過去了」</strong>而沒有成為創傷。</li>
</ul>
<p>什托姆普卡還指出：<strong>集體創傷不等於大規模創傷</strong>。後者只是數量概念，甚至可能強化團結，例如一場天災或一場抵抗外敵的戰爭（頁40）。</p>

<h3>四、集體記憶與身份認同</h3>
<p>關鍵在於：<strong>「是意義，而非事件本身，才提供了震驚和恐懼的感受。」</strong>（頁39）兩個例子：</p>
<ul>
<li><strong>Buffalo Creek 洪災（埃里克森）：</strong>洪水發生時<strong>不在場</strong>的居民，因為認同小鎮的人與土地，也出現了與在場者相似的反應。</li>
<li><strong>奴隸制（艾爾曼）：</strong>作為創傷的奴隸制，不是作為制度或經驗的奴隸制，而是「作為一種集體記憶的奴隸制」，成為非裔美國人的身份之根。這個創傷是<strong>回溯性</strong>的，由沒有親歷奴隸制的一代人闡釋出來（頁39）。</li>
</ul>

<h3>五、創傷過程：承載群體與四個問題</h3>
<p>事件與再現之間的距離，亞歷山大稱為<strong>「創傷過程」（trauma process）</strong>，它始於某些行動者的<strong>聲稱</strong>：宣稱某種根本損傷，並要求在情感、制度和符號上加以補償和重建（頁40–41）。</p>
<p>作出聲稱的是<strong>承載群體（carrier groups）</strong>（借自韋伯）：有資源在公共領域「製造意義」的群體，可以是精英，也可以是邊緣者。艾爾曼強調<strong>知識分子</strong>的作用，但知識分子是一種<strong>角色</strong>而非職業：記者、作家、專家，只要在公共領域闡釋「發生了什麼、誰該負責」，就在扮演知識分子（頁41–42）。</p>
<p>一個創傷聲稱要成功，必須回答四個問題（頁41）：</p>
<ol>
<li><strong>痛苦的本質：</strong>到底發生了什麼？</li>
<li><strong>受害者的性質：</strong>誰受了苦？</li>
<li><strong>與受眾的關係：</strong>「他們的痛苦」能否被讀成「我們的」？</li>
<li><strong>責任歸屬：</strong>施害者是誰？只是上一代，還是後代也要負責？</li>
</ol>

<h3>六、案例：劉文彩莊園與文化創傷的兩面</h3>
<p>據李海燕（Haiyan Lee）的研究，四川大邑的劉文彩莊園自1958年起被改為陳列館，布置了「水牢」；佃農冷月英以水牢「唯一倖存者」的身份作了近千場「憶苦思甜」報告；1965年的〈收租院〉泥塑則把個人的苦轉化為<strong>階級</strong>的創傷。1988年，水牢被宣佈不實。這正是「想像的事件也能造成創傷」的具體例子。</p>
<p>文化創傷因此有兩面：<strong>由下而上</strong>，受害者宣稱創傷、要求承認（如「傷痕文學」）；<strong>由上而下</strong>，政治權力強加創傷、動員仇恨（如〈收租院〉）。兩者用的是同一套機制，也未必能乾淨地分開。</p>

<h2>核心概念小結</h2>
<ul>
<li><strong>文化創傷：</strong>集體透過符號與表徵所建構的傷，必須動搖集體身份認同。</li>
<li><strong>自然主義謬誤：</strong>認為事件本身決定創傷。</li>
<li><strong>創傷潛力：</strong>事件提供可能性，但要經過命名與框定才成為創傷。</li>
<li><strong>承載群體：</strong>在公共領域作出創傷聲稱、製造意義的行動者。</li>
<li><strong>四個問題：</strong>痛苦的本質、受害者的性質、與受眾的關係、責任歸屬。</li>
</ul>
