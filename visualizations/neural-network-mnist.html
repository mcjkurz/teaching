How to use it

  • Press 訓練 Train to start learning. The network sees 8,000 handwritten digits (14×14 pixels, from MNIST) and is checked on 1,000 digits it never trains on.
  • Draw a digit on the pad, or press 測試圖 Test digit to load a random test image. Your drawing is cropped, rescaled and centred the same way MNIST digits were prepared.
  • Use − and + to change the number of hidden layers (0 to 4) and the neurons in each layer. Click a layer's label to switch its activation between ReLU, Sigmoid and 線性 none (linear).
  • Hover over a neuron to see the nine test images that activate it most. First-layer neurons also show their weights as a 14×14 picture. Click a neuron to keep only its own connections visible.
  • Keyboard: T train or pause, R reset, C clear the pad, N new test digit.

Things to try

  • Remove every hidden layer. The model is then a logistic regression on raw pixels, and it still reaches about 90% accuracy.
  • Set four wide layers to 線性 none. Accuracy stays near the logistic-regression level, because stacked linear layers collapse into a single linear layer.
  • Compare a learning rate of 0.0001 with a rate of 1. The first barely moves, and the second can make training diverge.
