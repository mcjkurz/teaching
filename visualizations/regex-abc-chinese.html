Cheat sheet

[一-鿿]any common CJK character (Unicode range 4E00–9FFF)
[㐀-䶿]CJK Extension A (rarer characters)
\p{Script=Han}any Han character, all extensions (works because this page uses the u flag)
[一二三]one character out of a set
[^一-鿿]one character that is not in the range
X+ X* X? X{1,2}repeat X: 1 or more / 0 or more / optional / between 1 and 2 times
(林|薛)either 林 or 薛
